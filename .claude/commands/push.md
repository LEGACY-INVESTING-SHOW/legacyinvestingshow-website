# Git Commit and Push

Commit all staged and unstaged changes, then push to the remote repository.

## Instructions

1. Run `git status` to see current changes
2. Run `git diff` to see what will be committed
3. Run `git log -3 --oneline` to see recent commit style
4. Stage all changes with `git add -A`
5. Create a commit with a descriptive message based on the changes, ending with:
   ```
   Co-Authored-By: Claude Opus 4.5 <noreply@anthropic.com>
   ```
6. Push to the current branch's remote
7. Report the result to the user
