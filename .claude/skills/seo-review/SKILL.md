# SEO & GEO Review Skill

Review and optimize a blog post for both traditional SEO and AI search (GEO).

## Arguments

$ARGUMENTS should contain the file path to review.

Example: `/seo-review content/blog/success-stories/sarah-johnson.md`

## Review Checklist

### 1. Frontmatter Validation

Read the file and check frontmatter:

#### Required Fields
- [ ] `title` - Present, under 60 characters, includes target keyword
- [ ] `description` - Present, 150-160 characters, includes keyword
- [ ] `date` - Valid date format (YYYY-MM-DD)
- [ ] `author` - Present (should be "Preston Seo")
- [ ] `category` - Present and valid category
- [ ] `image` - Present and file exists

#### Recommended Fields
- [ ] `modifiedDate` - Present for content freshness signal
- [ ] `tags` - Array with 3-5 relevant tags
- [ ] `faq` - Array with 3-5 FAQ items
- [ ] `statistics` - Array with 3+ statistics

### 2. GEO Optimization (AI Search)

#### Answer-First Format (CRITICAL)
**Check first paragraph:**
- [ ] First sentence directly answers the title question
- [ ] Contains a specific number/statistic
- [ ] Under 80 words
- [ ] Can stand alone as a complete answer

**Example of good first paragraph:**
> "Starting an Airbnb arbitrage business typically costs $5,000-$15,000. This includes first month's rent ($2,000-$4,000), security deposit, furnishing ($2,000-$5,000), and initial supplies. According to Legacy Investing Show data, students who follow the complete system achieve positive cash flow within 60-90 days."

#### Statistics Check
**Princeton Study Finding:** Statistics boost AI citations by 40%

- [ ] Minimum 3 statistics in content
- [ ] Each statistic has a source/citation
- [ ] Statistics appear in frontmatter `statistics` array
- [ ] Numbers are specific (not "many" or "several")

#### FAQ Section
- [ ] FAQ section exists with H2 heading
- [ ] 3-5 questions formatted as H3
- [ ] Each answer is 2-4 sentences
- [ ] Questions match "People Also Ask" patterns
- [ ] FAQs match frontmatter `faq` array (for schema)

### 3. Traditional SEO

#### Title Tag
- [ ] Under 60 characters
- [ ] Target keyword in first half
- [ ] Compelling/click-worthy
- [ ] Unique (not duplicate of other posts)

#### Meta Description
- [ ] 150-160 characters
- [ ] Includes target keyword
- [ ] Has call-to-action or value proposition
- [ ] Matches content intent

#### Headings Structure
- [ ] Single H1 (the title)
- [ ] Logical H2 structure (main sections)
- [ ] H3 for subsections
- [ ] Keywords in some headings naturally

#### Content Quality
- [ ] Minimum 1,200 words
- [ ] No thin sections (each H2 has 100+ words)
- [ ] No keyword stuffing
- [ ] Natural language

#### Internal Links
- [ ] Links to relevant blog posts (2-5 links)
- [ ] Links to /programs page
- [ ] Links to /about if mentioning Preston
- [ ] Anchor text is descriptive (not "click here")

#### External Links (if any)
- [ ] Sources are authoritative
- [ ] Links are relevant to claims
- [ ] No broken links

### 4. E-E-A-T Signals

#### Experience
- [ ] Contains real examples or case studies
- [ ] References actual student results
- [ ] Shows firsthand knowledge

#### Expertise
- [ ] Author attribution present
- [ ] Technical accuracy verified
- [ ] Industry terminology used correctly

#### Authoritativeness
- [ ] Links to credible sources
- [ ] Data from reputable organizations
- [ ] No unsupported claims

#### Trustworthiness
- [ ] No exaggerated claims
- [ ] Disclaimers where appropriate
- [ ] Contact information accessible

### 5. Schema Markup Readiness

#### Article Schema (auto-generated by build)
- [ ] Title matches frontmatter
- [ ] Author schema will populate
- [ ] Date fields present

#### FAQ Schema
- [ ] FAQs in frontmatter `faq` array
- [ ] Question/answer format correct
- [ ] Answers are self-contained

#### VideoObject Schema (if YouTube video)
- [ ] `youtubeId` in frontmatter
- [ ] Video embedded in content

### 6. Image Optimization

- [ ] Image file exists at specified path
- [ ] `imageAlt` is descriptive (not just filename)
- [ ] Image is optimized (WebP format available)
- [ ] Open Graph image dimensions (1200x630 ideal)

## Common Issues & Fixes

### Issue: First paragraph doesn't answer the question
**Fix:** Rewrite first paragraph to directly answer title question with a statistic.

### Issue: No statistics in content
**Fix:** Add 3+ statistics with sources. Use data from:
- AirDNA (market data)
- Legacy Investing Show student data
- Industry reports

### Issue: Missing FAQ section
**Fix:** Add FAQ section with questions from Google "People Also Ask" for target keyword.

### Issue: Thin content sections
**Fix:** Expand each H2 section to 150+ words with specific details.

### Issue: No internal links
**Fix:** Add links to:
- Related blog posts
- /programs page
- Success stories
