What this calculates

Amortize a mortgage with optional extra principal to estimate when LTV hits 80% and how much PMI you still pay before then.

How to use it

  1. Use today's balance and a conservative value, not list price.
  2. If extra principal is zero, you are waiting on scheduled amortization only.
  3. Ask the servicer whether they need an appraisal at 80%.

Common mistakes

  • Using original purchase price after a price drop.
  • Forgetting PMI does not automatically vanish at 80% on all loans.
  • Counting a cash-out refinance as removal without modeling the new loan.

Formula

Each month: balance -= scheduled principal + extra. Stop when balance ÷ value ≤ 80%.

FAQ

Is 80% or 78% the rule?+

Borrowers can often request cancellation at 80% LTV. Automatic termination is commonly 78% of original value. Confirm with the servicer.

Does extra payment always win vs investing?+

Only if the after-tax PMI plus mortgage rate beats expected invested return. Pair with the mortgage vs index tool.

What if value rose a lot?+

Raise the value input. That can hit 80% without extra payments.
