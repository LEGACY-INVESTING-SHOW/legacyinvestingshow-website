# Ideation Output Spec

## Required Files

- `ideation-priority.md`
- `ideation-backlog.csv`

## Backlog Columns

- topic
- primary_keyword
- intent
- persona
- format
- freshness_signal
- competition_estimate
- conversion_potential
- priority
- next_skill

## Priority Bands

- P1: publish soon (next 7-14 days)
- P2: active backlog
- P3: watchlist/seasonal
