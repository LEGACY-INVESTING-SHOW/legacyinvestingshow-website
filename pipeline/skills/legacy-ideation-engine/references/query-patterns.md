# Query Patterns

## Expansion Matrix

- Informational: `how`, `what`, `guide`, `steps`, `mistakes`
- Comparative: `vs`, `best`, `alternative`, `difference`
- Transactional: `template`, `calculator`, `service`, `tool`
- Freshness: append current year and previous year
- Social proof: append `reddit`, `youtube`, `x`, `forum`

## Minimum Search Set per Seed

1. `<seed> <year>`
2. `how to <seed>`
3. `<seed> mistakes`
4. `<seed> vs`
5. `best <seed> for beginners`
6. `<seed> reddit`
7. `<seed> case study`
8. `<seed> faq`
