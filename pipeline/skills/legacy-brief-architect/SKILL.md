# Legacy Brief Architect

Translate research into a strict content blueprint that reduces writing ambiguity.

## Workflow

1. Parse dossier.
2. Define intent and narrative strategy.
3. Build section plan and evidence mapping.
4. Specify SEO/AEO constraints.
5. Output lock-ready brief.

## Step 1: Parse Dossier

Read the full research dossier and extract:

- non-negotiable claims
- citations to preserve
- uncertain claims to avoid or caveat
- best user questions

## Step 2: Define Narrative Strategy

Set:

- target reader state (beginner/intermediate)
- core transformation promise
- point of view and tone
- preferred content format (guide/list/comparison/case study)

## Step 3: Section Architecture

Create section plan with:

- section objective
- key points
- evidence source anchors
- CTA linkage

Require clear H2/H3 hierarchy and one H1.

## Step 4: SEO + AEO Specifications

Include:

- title options
- meta description options
- primary and support keyword map
- FAQ targets for answer engines
- entity coverage list
- internal links and anchor suggestions

## Step 5: Output

Produce `brief.md` with:

- frontmatter requirements
- heading skeleton
- evidence requirements
- prohibited claims
- acceptance criteria for reviewer

Then handoff to `legacy-longform-writer`.
