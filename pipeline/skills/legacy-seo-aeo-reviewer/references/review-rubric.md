# Review Rubric

## Gate Rules

- Fail on any P0/P1 finding.
- Pass requires score >= 85.

## Severity

- P0: publication blocker (factual or structural critical). Missing `## Quick Take` as the first H2 is P0. FAQ entries that are not questions are P0.
- P1: high impact quality risk, including new tax/stat/formula claims without `sourceUrl`
- P2: medium optimization issue
- P3: minor improvement
