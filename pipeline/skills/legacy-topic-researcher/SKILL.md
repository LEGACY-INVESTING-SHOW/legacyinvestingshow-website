# Legacy Topic Researcher

Turn one approved topic into a research dossier that can power a high-quality brief.

## Workflow

1. Lock topic scope.
2. Gather sources with web search.
3. Extract evidence and contradictions.
4. Build source-backed insight map.
5. Output dossier.

## Step 1: Lock Scope

Input required:

- selected topic title
- primary keyword
- target persona
- target format

Define exclusions to avoid scope creep.

## Step 2: Gather Sources

Web search is required for this skill.

Collect minimum source mix:

- 3 authoritative sources (government, primary docs, official docs)
- 3 practical sources (case studies, practitioner breakdowns)
- 2 community sources (forums/social with caution)
- 2 competitive content pages targeting same intent

Track publish date for freshness-sensitive claims.

## Step 3: Extract Evidence

For each source capture:

- claim
- evidence snippet summary
- confidence level
- recency
- bias/risk notes

Flag contested or uncertain claims for reviewer attention.

## Step 4: Insight Map

Create structured sections:

- what users ask most
- where current content is weak
- data points suitable for citation
- narrative angles with high practical value
- internal links to existing site pages

## Step 5: Output

Produce `research-dossier.md` with:

- topic summary
- key findings
- evidence table
- citation list
- suggested outline directions
- handoff to `legacy-brief-architect`
